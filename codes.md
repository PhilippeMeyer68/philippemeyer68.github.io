<section class="section">
  <div class="section-header">
    <h3 class="section-title">Code</h3>
  </div>
  <p>
    Here are the codes I have developed or co-developed. They range from Python packages available on conda-forge or PyPI to repositories supporting my papers, mainly in cheminformatics and synthetic biology. Each name links to its GitHub repository, and the associated paper, when there is one, is linked after the description.
  </p>
<ul>

<li>
  <strong><a href="https://github.com/brsynth/morganbiopilot" target="_blank" rel="noopener">Agentic Retrobiosynthesis</a>: </strong>
  MorganBioPilot, a retrobiosynthesis framework in which a language model decides which molecule to expand next, on top of a deterministic search engine operating in ECFP fingerprint space.
  <a href="https://arxiv.org/abs/2608.30702" target="_blank" rel="noopener">Paper</a>
</li>

<li>
  <strong><a href="https://github.com/brsynth/morganrxn" target="_blank" rel="noopener">Vectorized Reactions</a>: </strong>
  morganrxn, a Python package representing chemical and enzymatic reactions as vectors in ECFP fingerprint space, for fast applicability filtering of reaction rules and reaction classification.
  <a href="https://doi.org/10.26434/chemrxiv.15006884/v1" target="_blank" rel="noopener">Paper</a>
</li>

<li>
  <strong><a href="https://github.com/brsynth/mutant-covid" target="_blank" rel="noopener">Metabolic Biosensors</a>: </strong>
  Machine learning models and GAMM statistical analyses for COVID-19 prognosis and diagnosis from the full growth curves of engineered <em>E. coli</em> biosensor strains.
  <a href="https://doi.org/10.64898/2026.08.04.740108" target="_blank" rel="noopener">Paper</a>
</li>

<li>
  <strong><a href="https://github.com/brsynth/bacterial_rc" target="_blank" rel="noopener">Bacterial Reservoir Computing</a>: </strong>
  Notebooks and trained models showing how living bacteria can serve as reservoir computers for information processing and sensing.
  <a href="https://www.cell.com/cell-systems/fulltext/S2405-4712(26)00136-5" target="_blank" rel="noopener">Paper</a>
</li>

<li>
  <strong><a href="https://github.com/brsynth/molecule-signature" target="_blank" rel="noopener">Reverse Engineering</a>: </strong>
  molecule-signature, a Python package available on <a href="https://anaconda.org/conda-forge/molecule-signature" target="_blank" rel="noopener">conda-forge</a> that recovers molecules from their ECFP (Morgan) fingerprints by deterministic enumeration based on molecular signatures.
  <a href="https://doi.org/10.1186/s13321-025-01074-5" target="_blank" rel="noopener">Paper</a>, <a href="https://github.com/brsynth/molecule-signature-paper" target="_blank" rel="noopener">Paper code</a>, <a href="https://philippemeyer68.pythonanywhere.com" target="_blank" rel="noopener">Application</a>
</li>

<li>
  <strong><a href="https://github.com/PhilippeMeyer68/linear-diophantine" target="_blank" rel="noopener">Linear Diophantine Systems</a>: </strong>
  lineardiophantine, a Python package available on <a href="https://pypi.org/project/lineardiophantine/" target="_blank" rel="noopener">PyPI</a> that solves linear Diophantine systems over the natural numbers with the Contejean–Devie algorithm, and over the integers with the Smith normal form.
</li>

<li>
  <strong><a href="https://github.com/PhilippeMeyer68/glyph-SNN" target="_blank" rel="noopener">Glyph Similarities</a>: </strong>
  Siamese neural networks that measure similarities between glyphs and writing systems, used to map and cluster 51 historical European, Mediterranean and Middle Eastern scripts.
  <a href="https://aclanthology.org/2024.lt4hala-1.12/" target="_blank" rel="noopener">Paper</a>, <a href="{{ '/glyph.html' | relative_url }}" target="_blank" rel="noopener">3D view</a>
</li>

<li>
  <strong><a href="https://github.com/PhilippeMeyer68/body-TDA" target="_blank" rel="noopener">Human Body Shapes</a>: </strong>
  Topological data analysis of 3D human body meshes with persistent homology, for anomaly detection and body shape classification.
  <a href="https://doi.org/10.3390/a16030161" target="_blank" rel="noopener">Paper</a>
</li>

</ul>

</section>
